# AWS S3 Static Website Hosting

## Project Overview
This project demonstrates how to host a static
website using Amazon S3.

## AWS Services Used
- Amazon S3

## Technologies
- HTML
- AWS Management Console
- Git
- GitHub

## Project Steps
1. Create an S3 bucket.
2. Upload website files.
3. Enable static website hosting.
4. Configure website permissions.
5. Access the website using its endpoint.
